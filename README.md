# Roguelite

A simple, casual roguelike in the spirit of NetHack: turn-based dungeon crawling on a grid, procedurally generated levels, permadeath, and lots of small interactions between items and monsters, but quicker to pick up and lighter to play.

This is an original game. It takes inspiration from the genre, not content from any existing game.

## Status

Early planning. The platform and language haven't been decided yet.
